# IZtun

**Легкий графический клиент AmneziaWG-GO для ARM64 Linux.** Разработано **IZMYSH**.

Загрузите конфиг VPN, подключитесь и управляйте профилями через нативное окно GTK или системный трей.

[Скачать](https://github.com/izmysh/iztun/releases/latest) · [Ручная сборка](BUILDING.ru.md) · [Безопасность](SECURITY.md)

## Что нужно

ARM64-компьютер с Debian/Ubuntu/Armbian, systemd и рабочим столом, а также
работающий сервер AmneziaWG и его клиентский файл `.conf`.
Для разовой настройки доступа у вашей учетной записи должны быть права sudo.

Для готового пакета нужна **glibc 2.38 или новее**. Приложение проверено на
Orange Pi 5 с ARM64 Armbian/Ubuntu. Другие ARM64-платы могут работать,
но пока не проверялись. Пакет не подходит для x86-64 и 32-битного ARM.

## Установка

1. Скачайте [пакет .deb для ARM64](https://github.com/izmysh/iztun/releases/download/v0.3.2/iztun_0.3.2_arm64.deb).
2. Откройте терминал в папке со скачанным файлом и выполните:

```bash
sudo apt install ./iztun_0.3.2_arm64.deb
```

3. Откройте **IZtun** из меню приложений. Если доступ еще не настроен, нажмите
   **Authorize** и при запросе введите пароль вашей учетной записи sudo в графическом окне.
   Дополнительные команды и выход из сеанса не нужны.

**Отдельно устанавливать или компилировать движок не нужно.** В `.deb` уже включены
собранные для ARM64 [AmneziaWG-GO](https://github.com/amnezia-vpn/amneziawg-go)
и [amneziawg-tools](https://github.com/amnezia-vpn/amneziawg-tools), а также IZtun.
Пакет называется `iztun`; при установке он заменяет старый пакет `amneziawg-linux-gui`.
Если `apt` не находит зависимость, выполните `sudo apt update` и повторите установку.

## Использование

- **+** - загрузить профиль из файла `.conf`.
- **Connect / Disconnect** - подключить или отключить VPN.
- **Auto-connect** - подключаться при загрузке системы.
- **⋮** - переименовать профиль, изменить конфиг, восстановить соединение или сохранить диагностику.
- Значок в трее позволяет управлять профилями без открытого окна.

Поддерживаются параметры AWG 2, 3 и 3.1. При подключении нового полного туннеля
предыдущий отключается. Если подключение не удалось, IZtun пытается вернуть
прежний VPN. Конфиг редактируется при отключенном профиле. Закрытие окна прячет
его в трей; выход из GUI не отключает VPN.

Свежий handshake подтверждает связь с сервером, но не гарантирует доступность
интернета или DNS. **Kill switch не реализован:** после ошибки или отключения
трафик может идти через обычное соединение.

## Установка из исходников

Скачайте [полный архив исходников](https://github.com/izmysh/iztun/releases/download/v0.3.2/iztun-0.3.2-source.tar.gz)
и распакуйте его через файловый менеджер. Откройте терминал в распакованной
папке и выполните **от обычного пользователя** одну команду:

```bash
bash scripts/install-from-source.sh
```

Установщик скачает зависимости, скомпилирует AmneziaWG-GO и его инструменты,
соберет пакет IZtun и установит его. При необходимости он запросит пароль
администратора. Нужен интернет. После установки откройте IZtun;
доступ при первом запуске настраивается через такое же графическое подтверждение.

Отдельная компиляция движка, проверка контрольных сумм, тесты и нестандартная
сборка описаны в [подробной инструкции](BUILDING.ru.md).
Сохраните исходники и компилятор для будущих обновлений.

## Если что-то не работает

- **Настройка отменена:** откройте IZtun снова и подтвердите **Authorize** от имени администратора.
- **Нет соединения:** проверьте сервер и конфиг, затем попробуйте **Repair connection**.
- **Нет трея:** включите StatusNotifier/AppIndicator в настройках панели.
- **Помощник недоступен:** см. [проверку службы](BUILDING.ru.md#проверка-службы).

GUI работает без `sudo`. Привилегированный помощник управляет маршрутами и DNS.
Добавляйте в группу `amneziawg` только доверенных пользователей: они могут читать
ключи через редактор. Не публикуйте конфиги VPN и снимки окна редактора.

## Обновление и удаление

Новый `.deb` устанавливается таким же способом. Для удаления сначала отключите VPN:

```bash
sudo apt remove iztun
```

Профили в `/etc/amneziawg`, резервные копии удаленных профилей и папка исходников сохраняются.

## О проекте

IZtun - независимый графический интерфейс и менеджер подключений, а не форк
VPN-движка и не официальное приложение Amnezia.
[AmneziaWG-GO](https://github.com/amnezia-vpn/amneziawg-go) - реализация протокола
AmneziaWG на Go: этот движок обрабатывает зашифрованный VPN-туннель.
IZtun управляет им через инструменты исходного проекта, не создавая собственный
протокол или криптографию.

Включение движка в пакет не превращает IZtun в его форк. Исходники зафиксированной
версии движка включены в полный архив исходников. IZtun и AmneziaWG-GO
распространяются под MIT, инструменты - под GPL-2.0. Уведомления об авторских
правах и лицензии исходных проектов сохранены.
